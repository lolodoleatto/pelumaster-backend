# 💈 PeluMaster - Backend

API RESTful desarrollada con **NestJS** para la gestión integral de turnos de una peluquería. Este sistema maneja la lógica de negocio y persistencia de datos necesaria para la plataforma PeluMaster.

## 📋 Descripción del Proyecto

El backend de PeluMaster proporciona los servicios necesarios para:
* ABM de Clientes, Barberos y Servicios.
* Agenda y Reserva de Turnos.
* Creación de reportes analíticos.
* Historial de Clientes.

Construido con una arquitectura modular y escalable, priorizando el rendimiento y la mantenibilidad del código.

## 🛠️ Tecnologías

* **Framework:** NestJS
* **Lenguaje:** TypeScript
* **Base de Datos:** MySQL (con TypeORM)
* **Entorno:** Node.js

## 🚀 Instalación y Ejecución

1.  Clonar el repositorio:
    ```bash
    git clone <URL_DEL_REPOSITORIO>
    ```
2.  Instalar dependencias:
    ```bash
    npm install
    ```
3.  Configurar variables de entorno (`.env`).
4.  Ejecutar en desarrollo:
    ```bash
    npm run start:dev
    ```

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests
